# Capturerer - releases

Android-APK's van Capturerer, de app die ingesproken of getypte tekst sorteert naar Google Agenda en TickTick. Dit repo bevat alleen de gebouwde versies; de broncode is niet openbaar.

De nieuwste versie staat op de pagina Releases als `capturerer-<versie>.apk`. De app leest zelf de nieuwste release (tag `v<versionCode>`) en vraagt bij het openen of je wilt bijwerken. Zoeken kan ook onder Instellingen, Updates.
